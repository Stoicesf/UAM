# 中文 Highlights — AC-DSGF v1

**题目：** 面向通信约束多无人机蜂群协同的自适应拓扑学习

### 1.
将通信拓扑从固定基础设施提升为软预算决策变量：*何时、与谁通信*。

### 2.
AC-DSGF 可微稀疏学习：Candidate Edge Scoring → Budget-Constrained Edge Selection → Residual Recovery。

### 3.
理论作为解释：度约束规模界 \(\eta_N=\mathcal{O}(1/N)\)；残差*动作*稳定性；门控为预算边选择的*近似/诱导*解（非显式求解器）。

### 4.
Identical / hard 预算下协同可比；主要收益是显著更低的 SCA（软激活），而非“最佳 Top-\(K\) 邻居”。
