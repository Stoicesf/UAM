# 运输桥鲁棒性压力测试报告

**分支**: `feature/cleanup-core`  
**标签**: `v2.3-transport-live`  
**日期**: 2026-09-06  
**环境**: WSL2 Ubuntu 22.04 + AAS Docker (ROS2 Jazzy) + Gazebo SITL  

## 测试目的
在 Gazebo 物理仿真中验证运输桥启发式控制器在以下扰动下的表现：
- 负载质量变化（+50%）
- 中等风力扰动
- 单根绳索断裂

## 测试配置
- 无人机数量: 4 架（重型机型，mass=1.2kg，T_max=12N）
- 负载质量: 5.0kg（基准）
- 目标距离: 5.0m
- 绳索参数: k=50N/m, d=5N·s/m, L0=2.0m
- 每场景运行 200 步（10 秒仿真时间）

## 结果汇总

| 场景 | 初始距离 (m) | 终局距离 (m) | 编队误差 (m) | 接受状态 | 备注 |
| :--- | ---: | ---: | ---: | :---: | :--- |
| **负载 +50%** | 5.00 | **0.28** | 0.11 | ✅ OK | 控制器成功适应，到达时间略增 |
| **风力 1.0 m/s** | 5.00 | **0.26** | 0.09 | ⏭️ SKIP | 风扰未显著影响性能（skip 仅表示不纳入核心验收） |
| **断绳（0 号 UAV）** | 5.00 | **14.68** | 2.64 | ⏭️ SKIP | 负载失控，剩余 UAV 无法平衡力矩（预期边界） |

## 详细数据

### 场景 1：负载 +50%
- `payload_mass_scale=1.5`
- 终局距离: 0.28m（远优于 5.0m 目标）
- 编队误差: 0.11m（<0.8 门槛）
- **结论**: 控制器在负载增加时仍能有效搬运，鲁棒性良好。

### 场景 2：风力 1.0 m/s
- `wind_strength=1.0`
- 终局距离: 0.26m（与基准相当）
- 编队误差: 0.09m
- **结论**: 中等风力对编队和运输影响可忽略（可能因风扰模型在 VMAS 中已做过相似测试）。

### 场景 3：断绳（0 号 UAV）
- `cable_break_idx=0`
- 终局距离: 14.68m（远离目标）
- 编队误差: 2.64m
- **结论**: 单根绳索断裂导致负载失去平衡，剩余 UAV 无法独立恢复，控制器缺乏应对断绳的冗余机制。这是当前架构的已知边界。

## 结论
1. **负载变化** 和 **风力扰动** 在设定范围内均被控制器有效抑制。
2. **断绳故障** 是当前设计的短板，需要引入载荷重分配或冗余控制策略。
3. 整体控制器鲁棒性满足常规工况要求，但极端故障需额外处理。
