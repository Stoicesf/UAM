# Phase 1：混合系统形式化调研（CSCBF / 混合平坦性）

分支：`feature/theory-hybrid-formal`  
对照代码：[`environments/dynamics/hybrid_payload.py`](../../environments/dynamics/hybrid_payload.py)

## 1. 背景

多机吊运在缆绳松弛/拉紧切换时呈现混合动力学：连续流（弹簧-阻尼张力）+ 离散跳变（冲击重置）。工程实现常用滞回状态机；形式化目标是将守卫、重置映射与安全证书（CBF 族）写进同一混合系统框架，并讨论切换下是否仍保持微分平坦性。

## 2. 相关工作要点（调研提纲）

- **混合系统**：守卫条件、重置映射、Zeno / 抖振；滞回作正则化。
- **吊运与绳系机器人**：slack-taut 切换、非弹性冲击近似、载荷摆振抑制。
- **CBF / 高阶 CBF**：连续系统安全不变集；扩展到混合模式需模式依赖证书或公共证书。
- **微分平坦**：吊运文献中的平坦输出（载荷位姿、张力相关量）；混合模式下平坦性通常只在固定离散模式下成立，切换需额外论证。

> Phase 1 产出为差距分析与问题清单；正式文献表与证明在 Phase 2（`docs/cscbf_theorem.*`、`docs/differential_flatness_hybrid.*`）。

## 3. 相对本仓库现状的差距

| 现有实现 | 形式化缺口 |
|----------|------------|
| 每绳 `state ∈ {0,1}`，滞回 `hysteresis` 切换 | 无显式混合自动机 \(\mathcal{H}=(X,Q,f,E,G,R)\) 定义 |
| slack→taut 时 `_impact_reset`（沿绳投影非弹性） | 重置映射未证明能量耗散 / 不增加不安全集 |
| taut 段弹簧-阻尼 + `clamp(T≥0)` | 连续流未写成控制仿射形式 \(\dot x=f_q+g_q u\) |
| `g=0` 的 2D 俯视 | 与 3D 带重力吊运论文设定不一致；证明需先声明工作空间 |
| 安全层为 APF + `project_action`，与缆绳状态解耦 | **无 CSCBF**：屏障不依赖 `state`，切换尖峰无证书 |
| env 工程 tow / 软伺服可掩盖切换瞬态 | 形式化验证需可关闭工程辅助的“纯混合”模式 |

## 4. Phase 2 理论问题清单

1. 定义状态 \(x=(\mathrm{pos}_L,\mathrm{vel}_L,\{\mathrm{state}_i\})\) 与模式依赖向量场。
2. 写出守卫 \(G_{0\to1}, G_{1\to0}\)（与现滞回一致）与重置 \(R_{0\to1}\)。
3. 设计 **CSCBF**：\(h(x,q)\) 使 taut/slack 下安全集正向不变；切换瞬间 \(h\) 不降到负。
4. 论证（或反例）混合系统在固定 taut 模式下的平坦输出；切换下采用“模式内平坦 + 重置后重规划”。
5. 给出可数值检查的引理陈述（能量、张力有界、无 Zeno）。

## 5. 验收门槛（对齐总方案）

| 阶段 | 门槛 |
|------|------|
| Phase 1（本文件） | 明确状态机↔形式化差距；问题清单可进入证明 |
| Phase 4（仿真） | CSCBF 下切换无数值尖峰；安全边界严格满足 |
